# Legendary Mobile Detailing

Official website for **Legendary Mobile Detailing**, an owner-operated mobile detailing business run by John Bauer in Beaufort, South Carolina.

## Stack

Dependency-free static site:
- `index.html` — site, styles, and quote-request interaction
- `assets/legendary-logo.svg` — vector brand mark
- `vercel.json` — Vercel headers and static-site configuration
- `robots.txt` — crawler policy

## Deployment

Designed for Vercel with no build command. Deploy the repository root.

## Contact

The site intentionally does not invent a phone number, email address, pricing, or business hours. Add John's preferred business contact information when available.
